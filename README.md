# Darwin's Dilemma 🧬

**Can cooperation survive in a world driven by self-interest?**

Darwin's Dilemma is an interactive artificial-life simulator that explores the evolution of cooperation through the Prisoner's Dilemma and evolutionary game theory.

Design strategies, release them into a living ecosystem, and observe how cooperation, betrayal, competition, and survival shape the world over time.

## 💡 The Idea

What happens when intelligent agents repeatedly interact in a world with limited resources?

In Darwin's Dilemma, each organism follows a behavioral strategy. Organisms interact with their neighbors, earn payoffs, compete for survival, and reproduce. Successful strategies can spread, while unsuccessful ones may disappear.

The resulting ecosystem lets users explore how simple decisions can lead to complex collective behavior.

## ✨ Planned Features

* **Living Ecosystem:** Visualize a grid of organisms with different behavioral strategies.
* **Strategy Simulation:** Experiment with Always Cooperate, Always Defect, Tit for Tat, and Generous Tit for Tat.
* **Evolution:** Model interactions, energy, survival, reproduction, and potentially mutation.
* **Axelrod Tournament:** Compare strategies through repeated Prisoner's Dilemma matches.
* **Real-Time Analytics:** Track population sizes, cooperation rates, and strategy performance.
* **Interactive Experiments:** Change the rules and observe how the ecosystem responds.

## 🧪 Research Questions

* Can cooperation emerge among self-interested agents?
* When does a forgiving strategy outperform a retaliatory one?
* How do local interactions affect the survival of cooperative strategies?
* Can a strategy that performs well in a tournament also dominate a spatial ecosystem?

## 🚀 Getting Started

Once the initial application has been implemented:

```bash
git clone <your-repository-url>
cd darwins-dilemma
npm install
npm run dev
```

Open the local URL printed by Vite to explore the application.
